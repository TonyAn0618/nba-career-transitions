# Shot Atlas · NBA 生涯转型

选择球员与参考赛季，寻找当时年龄、投篮分布和出手量相近的历史球员，比较他们随后三年的打法、效率和产量变化。默认案例为 Stephen Curry 的 2021–22 赛季。页面保留按阶段对齐的生涯堆叠柱，柱图、条形对照、球场图和趋势图共享当前阶段与投篮区域。当前视图可以通过网址分享。

## 本地运行

首次安装需要 Node.js 22.12+、npm、Python 3.10+、curl 和网络。在仓库根目录执行以下命令。

```sh
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:5181/>。Mac 也可以双击 `start.command`。首次启动会从固定版本的数据源导入赛季统计和投篮坐标，已有数据时会跳过。生成的网页数据占用约 492 MB，本地缓存和生成文件均由 Git 忽略。构建静态网站使用 `npm run build`，发布目录为 `dist/`。网页支持部署到域名根目录或仓库子路径。

## 如何阅读

- 先选择参考赛季。年龄默认精确匹配，也可放宽为相差一岁，并可按后卫、前锋、中锋筛选。参考季须有完整五区占比、正的上场时间、年龄和至少 200 次出手。
- 历史匹配只用当时的信息：五区投篮占比重合度占 80%，每 36 分钟出手量比值占 20%。占比先校正舍入误差。历史参考季必须更早；每位历史球员只保留一个最接近的赛季，展示前 8 人。权重是设计选择。后续结果与样本完整性不影响排名。
- 点选生涯堆叠柱或阶段按钮，联动条形图、球场图与三张趋势图；悬停趋势阶段可临时查看，点击固定。选择投篮区域只改变查看内容，不重新计算相似度。条形图可比较占比或相对各自参考季的变化。
- 所有追踪冻结在当前球员所选的参考赛季，不提前展示当前球员之后的真实记录，也不使用当时尚未发生的历史球员后续。球场保留当前球员参考季、历史球员参考季及所选后续阶段的对照，不制造未来坐标。
- 转型参考列出增加、维持、减少某一区域出手的案例及效率、得分产量变化中位数。占比变化在 ±2 个百分点以内记为维持。缺失值和不足 200 次出手的案例保留在明细中，但不计入汇总；各指标分别显示有效样本数。历史关联不证明改变投篮选择导致了表现变化，也不代表预测成功概率。
- 「参考季之前的生涯」保留历史转型回顾。该功能不参与新的风格匹配。

## 数据与组员协作

赛季统计覆盖 1996–97 至 2024–25，来自 Basketball-Reference 的固定版本汇编。投篮坐标覆盖 2003–04 至 2024–25，通过索引按球员和赛季加载。缺失记录和真实的零值分别处理。[赛季来源清单](data/source-manifest.json) · [逐球数据与坐标说明](docs/shot-data.md)

| 要修改的内容       | 从哪里入手                                                                                                                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 赛季或球员统计     | 使用 `playerId` 和赛季结束年份关联记录，在 `scripts/sync-data.mjs` 更新来源和导入逻辑。新增年份时一并更新来源校验与覆盖范围，运行 `npm run data`。                   |
| 球员头像           | 将核实的 NBA 260 × 190 PNG 按球员 ID 命名放入 `public/players/`，运行 `npm run photos` 更新映射并核对清单。缺图时页面显示姓名缩写。[头像来源](docs/photo-sources.md) |
| 风格匹配与后续样本 | `src/lib/style-paths.ts` 包含评分、年龄与位置筛选、观察截止日期及汇总规则。                                                                                          |
| 叙事与图表联动     | `src/components/CareerPathExplorer.tsx` 管理参考赛季、历史球员、阶段和区域，`CareerPathStacks.tsx` 展示生涯构成，`LocationCourts.tsx` 展示真实坐标。                 |
| 历史转型回顾       | `src/lib/career-shifts.ts` 保留此前的变化识别；旧转型匹配模块保留供对照，不再驱动首页。                                                                              |

更新球员身份映射、赛季出手总数或坐标来源后，运行 `npm run data:shots` 重建坐标索引。已有完整缓存时可以运行 `python3 scripts/sync-shots.py --offline` 离线重建。组员提交源码、头像、锁文件和数据清单即可，新克隆的项目会自行生成数据。
