# Shot Atlas · NBA 生涯转型

从一个年龄出发，探索 NBA 球员如何改变五个距离区间的出手分布、命中率和得分效率，再用历史同龄球员的实际后续表现建立转型参照。默认案例是勒布朗·詹姆斯，旧的区间比较仍可从「数据与方法」进入。

## 本地运行

首次安装需要 Node.js 22.12+、npm、Python 3.10+、curl 和网络。在仓库根目录执行以下命令。

```sh
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:5181/>。Mac 也可以双击 `start.command`。首次启动会从固定版本的数据源导入赛季统计和投篮坐标，已有数据时会跳过。生成的网页数据占用约 493 MB，本地缓存和生成文件均由 Git 忽略。构建静态网站使用 `npm run build`，发布目录为 `dist/`。网页支持部署到域名根目录或仓库子路径。

## 年龄与转型

- **生涯与出手**。同心年轮由内向外读年龄，圆周版沿外缘顺时针读年龄。悬停或轻触可局部放大，年龄轴支持键盘选择。「双图对照」同步两种视图。饼图显示所选赛季五个距离区的出手占比，两龄并排条形图可切换出手占比和区域命中率。效率曲线显示球员与当季联盟平均真实命中率的差，逐球场图对照两季的实际投篮位置。
- **同龄转型参照**。检索与所选基准赛季同龄、且发生在更早年份的球员。特征为五区出手占比、每 36 分钟出手和罚球出手比。标准化后用加权余弦排序；五区各权重 1，后两项各 0.5。符合 500 分钟或 200 出手的赛季即可进入比较池，保留没有多年后续的球员。沿 1–5 年的实际后续观察投篮变化、rTS 与样本数。每个未来年龄的类比区间来自前十参照中有配对记录者的变化，至少需三人。
- **球队与群体**。同季多队球员按球队拆分投篮；群体流图展示从 20–23 岁、25–28 岁到 31 岁以后的按位置筛选的投篮风格迁移。图中可查询流带人数、效率变化、观察期截止及无合格赛季的情况。
- **原版区间比较**。已有含 `from`、`to` 的链接仍进入连续赛季转型检测。原算法结合变化方向及幅度（60%）、起始分布（25%）与每 36 分钟出手量（15%）。

## 数据与组员协作

赛季统计覆盖 1996–97 至 2025–26（30 季、14,569 个球员赛季），来自 Basketball-Reference 的固定版本汇编。投篮坐标覆盖 2003–04 至 2024–25，通过索引按球员和赛季加载。缺失记录和真实的零值分别处理。[赛季来源清单](data/source-manifest.json) · [逐球数据与坐标说明](docs/shot-data.md)

| 要修改的内容         | 从哪里入手                                                                                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 赛季或球员统计       | 使用 `playerId` 和赛季结束年份关联记录，在 `scripts/sync-data.mjs` 更新来源和导入逻辑。新增年份时一并更新来源校验与覆盖范围，运行 `npm run data`。                   |
| 球员头像             | 将核实的 NBA 260 × 190 PNG 按球员 ID 命名放入 `public/players/`，运行 `npm run photos` 更新映射并核对清单。缺图时页面显示姓名缩写。[头像来源](docs/photo-sources.md) |
| 转型识别和 twin 排名 | `src/lib/age-peers.ts` 定义同龄检索与历史后续；`src/lib/career-shifts.ts` 和 `src/lib/transition-matches.ts` 用于原版区间比较。                                      |
| 球探建议             | `src/components/AgePeers.tsx` 展示历史后续、情景区间与持平基准。`scripts/backtest-age-peers.mjs` 复算按年份截断的回测。                                              |

更新球员身份映射、赛季出手总数或坐标来源后，运行 `npm run data:shots` 重建坐标索引。已有完整缓存时可以运行 `python3 scripts/sync-shots.py --offline` 离线重建。组员提交源码、头像、锁文件和数据清单即可，新克隆的项目会自行生成数据。
